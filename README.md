One sentence, at most 200 characters, about the best meal I ever had.

> I ate hilsa fried in mustard oil on a monsoon afternoon while rain hammered the tin roof, and the bones were worth every careful minute.

`main.py` (Python standard library only) writes that sentence to `/output/entry.txt` and checks it against the bounty gate first: UTF-8, 1–200 characters, not only white space, a single line, and ending with terminal punctuation.

## Run

```sh
python3 main.py
```
